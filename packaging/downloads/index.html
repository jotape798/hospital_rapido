Instalação sem surpresa

Os pacotes não levam banco, segredos ou credenciais do computador de desenvolvimento. No Windows, a primeira execução cria uma base local nova e solicita o administrador da instalação.

  1. Windows: extraia o ZIP inteiro e execute Iniciar_UBS_Rapida.bat. Não mova somente o executável.
  2. Android (não validado): o APK não teve o funcionamento confirmado em aparelho físico e não está aprovado para Play Store. Para testes futuros, ele deve ser compilado com o endereço acessível da API.
  3. Web (não publicado): use apenas em teste local servido por HTTP ou HTTPS. Não há hospedagem pública definitiva nem backend HTTPS configurado.

Requisitos mínimos

Windows
Windows 10 1809+, processador x64 e 500 MB livres.
Android
Android compatível com o mínimo definido pelo Flutter e acesso à API configurada.
Web
Navegador atual, JavaScript habilitado e conexão com a API por HTTPS em produção.

Uso acadêmico e dados fictícios

Este projeto demonstra fluxos de uma UBS com dados fictícios. Não substitui sistemas oficiais de saúde e não deve receber dados clínicos reais sem uma avaliação completa de segurança, privacidade, infraestrutura e conformidade.
