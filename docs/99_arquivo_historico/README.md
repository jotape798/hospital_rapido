# Arquivo histórico

Esta pasta guarda materiais substituídos ou de apoio que podem ter valor acadêmico, mas não são referência operacional do sistema.

> **Registro histórico — resultados substituídos pela auditoria final.** Contagens de testes, avaliações, escopos e estados de plataforma registrados nos arquivos desta pasta representam as etapas e datas em que foram produzidos. Eles não descrevem o estado final. Os resultados finais vigentes são 232 testes backend e 190 testes Flutter aprovados, com `flutter analyze` sem ocorrências; a entrega oficial é o aplicativo Windows desktop 0.1.0. Android não foi validado em aparelho físico e está fora da entrega oficial; Web/PWA também está fora da entrega oficial e não possui hospedagem pública.

- `acervo_documentacao_projeto/`: relatórios antigos, referências, imagens, PDF e cópia histórica de código;
- `planos_de_desenvolvimento/`: planos e especificações usados durante etapas anteriores.

Os arquivos daqui não são importados nem executados pela aplicação. Não use conteúdo histórico como instrução de instalação sem conferir os READMEs atuais.
